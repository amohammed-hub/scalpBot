# Full Codebase Audit Instructions

## Phases:
1. DISCOVERY - Read all files, document bugs in master bug list. STOP and show user.
2. FIX - Fix bugs in dependency order, test each fix.
3. INTEGRATION VERIFICATION - Full test suite, linter, build.
4. DEPLOYMENT - Only after Phase 3 is green and user confirms.

## Rules:
- No shortcuts, no skimming
- Document first, fix second
- Verify every fix
- No silent failures
